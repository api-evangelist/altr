# ALTR

> ALTR is a unified data security platform that discovers, classifies, masks, tokenizes and monitors
> sensitive data across Snowflake, Databricks and OLTP databases (PostgreSQL, MySQL, SQL Server,
> Oracle, MongoDB). This file is an API Evangelist-generated index of ALTR's public API surface — it is
> not published by ALTR.

Generated: 2026-08-06 by the API Evangelist enrichment pipeline (method: generated).
ALTR publishes no llms.txt of its own (https://altr.com/llms.txt and https://docs.altr.com/llms.txt both 404).

Authentication for every REST API below is HTTP Basic: username = API key name, password = API key
secret, created at Settings > Preferences > API in the ALTR console. There is no OAuth, no
idempotency key, and no RFC 9457 problem+json.
